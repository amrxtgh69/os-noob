STCF (Shortest Time-to-Completion First) still relies on the Oracle Problem but with preemption.

Key insight: Even with preemption, STCF requires knowing remaining runtime of all processes, which is impractical.

Example showing the limitation:
- Process A: arrival=0, runtime=100 (remaining=100)
- Process B: arrival=1, runtime=1 (remaining=1) 
- Process C: arrival=2, runtime=50 (remaining=50)

At time=1, we need to know that B has only 1 unit left to preempt A. But we cannot know this without oracle knowledge.

Learning focus: Recognize that both SJF and STCF are theoretically optimal but practically unimplementable due to the Oracle Problem, motivating heuristic approaches like MLFQ.
