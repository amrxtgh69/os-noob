MLFQ (Multi-Level Feedback Queue) solves the problems exposed by previous algorithms.

Problems it addresses:
1. Oracle Problem (SJF/STCF): Instead of requiring future knowledge, MLFQ learns from past behavior
2. Convoy Effect (FCFS): Short jobs can reach high-priority queues quickly
3. Response Time vs Turnaround Trade-off (RR): Uses multiple queues with different time slices to balance both

Key insight: MLFQ approximates SJF by observing that:
- Interactive jobs yield CPU quickly (stay in high-priority queues)
- CPU-bound jobs use full time slices (get demoted to lower queues)

Rules that make it work:
1. Priority: Higher priority queues run first
2. Same priority: Round Robin scheduling
3. New jobs: Start in highest priority queue
4. Full slice usage: Job demoted to lower queue
5. Periodic boosting: All jobs moved back to top queue to prevent starvation

Learning focus: Understand how MLFQ dynamically adapts to job behavior without needing future knowledge, making it practical for real systems.
